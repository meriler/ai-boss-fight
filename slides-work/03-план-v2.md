# План слайдов v2 — свод правок Codex R1 (7/10) + методист (7/10) + логик (7/10)

Самодостаточный документ (читается без v1). Формат: ТЕЗИС (на слайде) · ВИЗУАЛ (связь) · ЗА КАДРОМ (рельсы Игоря: тезисы + 1–2 фразы + ⛔).

## Инварианты v2 (дополнены)

1. До слайда C5 (код 4712) слова «размер/расстояние/фон/свет» не появляются НИГДЕ — ни на слайдах, ни в notes (в notes вместо стоп-списков одна фраза: «не называй разгадку и не предлагай варианты»).
2. **До C5 все карточки-примеры на слайдах — ОДИНАКОВОГО размера.** Размер как визуальный код включается только с C6.
3. Тезис ≤7 слов; определения пишутся НА слайде (Игорь не формулирует с нуля); длинное — в notes.
4. Честность: «твой ИИ» (единый термин, «модель» не употребляем на слайдах), хранилище — «альбом» (склейка «учебник = альбом» один раз, в B6). Механика: альбом + голосование похожих. Никаких «нейросеть учится/исправляется».
5. Цвет = класс (ладонь зелёный, кулак синий) и НИЧЕГО больше; ставки и нейтральное — серый/жёлтый.
6. Слайд-действие = эталон результата («выглядит так») + бейдж канала: «💬 в чат» / «🤖 в тренажёр» на КАЖДОМ действии.
7. Пиктограммы проверок ЕДИНЫ и повторяются буквально: B8 (3 случая) → C1 (те же 3) → D4 (те же 3 + 1 новый, помечен «новый!»). Реальность тренажёра: R1 = 3 замера, R2 = 4 — на слайдах не врать «та же проверка», а «те же задания + одно новое».
8. Карта миссии (5 шагов) возвращается с подсветкой текущего шага: мини-полоска в углу первых слайдов каждого блока (B1, C1, D1, E1) + финал E3 с галочками.
9. Эмоциональные крючки закрываются: ставка-1 → пейофф в C6; ставка-2 → пейофф после C1; «перевоспитаешь» из A3 → пейофф в D2; карта A4 → E3; несломавшаяся модель → ветки в C4/C6/D5.
