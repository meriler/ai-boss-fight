# slides-work — итеративная проработка презентации воркшопа (ночь 14.07)

Процесс (ТЗ Алексея, 14.07 ~01:00): структура → план послайдово (содержимое + закадровый текст Игоря)
→ Codex-ревью → правка → субагенты-критики → Codex → … до 10/10 обоих → сборка слайдов →
итеративная критика скриншотов до 10/10. Каждая итерация — отдельный файл здесь.

Файлы:
- 00-структура-v1.md — укрупнённая структура занятия и роль слайдов в каждом блоке
- 01-план-v1.md — послайдовый план v1 (слайд: визуал/тезис + закадровый план Игоря)
- 02-codex-r1.md — ответ Codex по плану v1 → 03-план-v2.md → 04-критика-субагентов.md → 05-план-v3.md …
- NN-* — далее по циклу; последний план = канон для сборки
- images/ — сгенерированные картинки (image-bridge)
- score.md — текущие оценки (Codex / Клава), стоп-критерий 10/10 + 10/10

Контекст: дети 10–12, онлайн (Телемост), Игорь — рассказчик-импровизатор (определения на слайде,
не в его памяти), запрет спойлеров разгадки до слайда-кода, честность (KNN=альбом+похожие),
слайд = инфографика связей (Ильяхов), не текст для чтения. База: ответ Codex «содержательная линия»
(scratchpad/codex_slides_out.txt, скопирован в 02-codex-r0.md).
