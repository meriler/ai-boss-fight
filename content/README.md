# content/ — занятия как ДАННЫЕ (критерий фазы 0)

Смена банка картинок, шагов, текстов, карточек = правка файлов ЗДЕСЬ, не кода.
Спека: vault `itmo/ai-school/01-воркшоп/ТЗ-демка-з1.md` (§3) + аннекс
`ТЗ-демка-з1-схема-манифеста.md` (нормативные реестры и инварианты).

## Структура

- `schema/` — нормативные JSON Schema 2020-12: `lesson` (манифест), `bank` (банк картинок),
  `journal` (словарь restore-журнала, ЗАКРЫТ на 14 типах). Новый тип шага/действия =
  правка спеки в vault + схем осознанным решением, не рефлекс (риск 3 ТЗ).
- `z1-kot/` — эталонный манифест З1 «Дело о коте, которого не было»
  (`lesson.json` + `bank.json` + `assets/`). Банк в `pilot_status: pending` —
  картинки-плейсхолдеры до пилота ловушек (§6 ТЗ); реальные кладутся поверх теми же именами.
- `_test-variant/` — тестовый манифест (яблоки/груши, подвох — цвет, переставленные шаги,
  другие тексты): доказательство критерия фазы 0 — тот же код, другой контент. Банк frozen
  на фикс-эмбеддингах (`?demo=1`), пилота не требует.
- `validate.mjs` — валидатор: схема + 11 инвариантов аннекса (лимит ≤5 на такт, ссылочная
  целостность, роли банка, ассеты, оба резерва, hints) + эталонная проходимость тем же
  кодом машины/редьюсера, что живой клиент (`app/core/`).
- `tools/make-placeholders.mjs` — создать 1×1 PNG для всех ссылок манифеста, которых нет
  в `assets/` (валидатор требует существования файлов).

## Команды

```bash
cd content && npm install        # один раз: ajv для валидатора
node content/validate.mjs        # все занятия; или node content/validate.mjs content/z1-kot
node content/tools/make-placeholders.mjs
../ci.sh                         # полный CI-набор локально
```

CI: `.github/workflows/content-ci.yml` — на каждый пуш с правкой `content/`/`app/`/`server/`
гоняет валидатор обоих манифестов + проходимость + тесты ядра и сервера (без браузера).
