- Раннер даёт ненулевой exit-код при `FAIL `/`EXCEPTION` в выводе (run-e2e.mjs :17) — цикл в верификации ловит падение по `||`.

- Мягкий stuck (15 с) в реальном времени замедляет прогон — если TASK-3 добавил query-param для сжатия таймера (по аналогии с `CFG` `biglo`/`smhi` через `QP.get`), использовать его; иначе ассерт держать одним, с увеличенным `waitForFunction` timeout.
