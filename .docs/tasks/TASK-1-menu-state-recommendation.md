## Технические заметки
- **C1 (методический блокер).** Метка на плитках — «таких у ИИ меньше всего 👀», НЕ «ИИ этого не видел» (это ложь: базовый поток обязательно прогоняет t2a/t2b до финала). `quadCounts()` материализует правду: статбаза 6/3/3/6, где меньше всего — t2a и t2b. Сам текст метки — в TASK-2.
- **Соответствие квадрант↔(cls,gate)** берётся из `TASKS` (:930), но для меню в TASK-3 набор строится с `need:3` для любого квадранта — здесь важно только для подсчётов и порядка.
- **size у примеров не хранится** (KNN.ex = {emb,pix,l}) — поэтому счёт по квадрантам считается из `MENU.taps` (лог тапнутых), а не из реальных кадров. Это сознательное решение ТЗ (F7): «size хранить не нужно».
- **Чистота функций.** `quadCounts`/`recommendedTiles`/`betterRes` — без побочных эффектов, читают только `MENU.taps`. Это позволяет e2e дёргать их напрямую через `window`.
